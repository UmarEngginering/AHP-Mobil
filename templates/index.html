Rumus Matematis AHP

1. Normalisasi Matriks: r_ij = a_ij / ∑(a_kj)
2. Bobot Prioritas: w_i = (1 / n) × ∑(r_ij)
3. Indeks Konsistensi: CI = (λ_max - n) / (n - 1)
4. Rasio Konsistensi: CR = CI / RI ≤ 0.10 (Konsisten)
